# 浮木

> 把想法整理成结构，把结构变成好看的图。

浮木（Fumu）是一款面向内容创作者、产品经理、咨询顾问、教师和团队协作者的信息图创作应用。  
你不需要从空白画布开始，也不必反复拖拽、对齐和连线：选择合适的模板，填写结构化内容，实时调整视觉风格，即可快速得到一张清晰、可编辑、可交付的信息图。

## 为什么是浮木？

传统 PPT 或白板工具通常要求你先“画图”，再把内容填进去。内容一旦变化，布局、连线和对齐往往都要重新调整。

浮木选择了另一种方式：

| 传统绘图方式 | 浮木 |
| --- | --- |
| 从空白画布开始 | 从成熟的内容模板开始 |
| 手动摆放节点和连线 | 用结构化数据驱动图形 |
| 内容变化后重复调整布局 | 内容、结构与画布保持同步 |
| 重点关注绘图细节 | 把精力放在信息组织和表达上 |

## 核心能力

### 1. 模板化表达

围绕不同的信息关系提供模板，让复杂内容拥有合适的表达方式：

- **数据图表**：趋势、占比、对比、指标和排行
- **流程说明**：产品流程、业务路径、项目阶段和决策过程
- **层级结构**：组织架构、知识体系、系统模块和目录关系
- **关系网络**：人物、组织、依赖、因果和协作关系
- **时间路线**：时间线、路线图、版本演进和里程碑
- **知识卡片**：课程内容、读书笔记、方法论和文章配图

项目当前提供超过 160 种预设模板，并持续扩展模板图库。

### 2. 所见即所得的 Studio

在 Studio 工作台中，可以直接编辑内容并实时查看结果：

- 表单化录入标题、节点、数据和关系
- 实时预览布局与渲染效果
- 调整主题、字体、颜色和视觉风格
- 根据内容变化自动更新图形结构
- 在桌面端和移动端保持良好的使用体验

### 3. 统一的视觉风格

通过风格和调色板快速改变信息图的整体气质，适配汇报、文章、课程、社交媒体和知识库等不同场景。系统会根据账号套餐控制可用的高级样式和调色板。

### 4. 从创作到交付

完成编辑后，可以将信息图用于：

- 产品和项目汇报
- 方案、报告和演示文稿
- 公众号、博客和知识库文章
- 课程讲义和培训材料
- 团队协作与内部文档

### 5. 套餐与权限体系

应用内置完整的订阅与配额能力：

- 不同套餐对应不同的模板、风格和调色板权限
- 导出次数按套餐额度管理
- 订阅状态与使用记录持久化保存
- 管理员可以维护模板、套餐和访问权限
